# Maps Prospect Finder

Chrome Extension Manifest V3 untuk membantu riset calon klien dari Google Maps.

## Cara mencoba

1. Buka `chrome://extensions`.
2. Aktifkan **Developer mode**.
3. Klik **Load unpacked** dan pilih folder proyek ini.
4. Buka Google Maps dan pastikan URL berada di domain Google Maps.
5. Klik icon extension, masukkan kata kunci dan jumlah hasil, lalu klik **Mulai pencarian**.
6. Setelah selesai, buka popup lagi dan klik **Export CSV**.

## Catatan

- Biarkan tab Google Maps tetap terbuka selama proses berlangsung.
- Data website berarti website yang ditampilkan pada profil Google Maps; `Belum ditemukan` tidak membuktikan bisnis tersebut tidak memiliki website.
- Google Maps dapat mengubah struktur halaman sehingga selector scraper mungkin perlu diperbarui.
- Gunakan secara wajar dan patuhi ketentuan layanan serta hukum yang berlaku. Extension ini tidak mencoba melewati CAPTCHA atau kontrol keamanan.
